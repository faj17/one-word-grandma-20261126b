One word, and nothing else: the single word a grandma would text about AI.

**witchcraft** — the baffled, warm verdict of a grandmother staring at a machine that answers back. She does not know how it works, she does not want to know how it works, and she is fairly sure it is witchcraft.

## Run it

```sh
python3 main.py
```

Writes the word to `/output/entry.txt`.
